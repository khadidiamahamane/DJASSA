# DJASSA 🛍️

**DJASSA** est une plateforme web qui associe une marketplace multi-vendeurs à un système de gestion de stock intégré.

Elle vise à simplifier la gestion des activités commerciales en réunissant dans un même espace la présentation des produits, leur commercialisation et le suivi des stocks.

## ✨ Fonctionnalités

- **Marketplace :** découverte et consultation des produits proposés par différents vendeurs.
- **Gestion des produits :** organisation et gestion du catalogue.
- **Gestion de stock :** suivi des disponibilités et des quantités de produits.
- **Espace vendeur :** outils dédiés à la gestion de l'activité commerciale.
- **Interface intuitive :** une expérience pensée pour faciliter l'utilisation de la plateforme.

## 🛠️ Technologies

- Next.js
- React
- TypeScript
- Tailwind CSS
- Prisma

## 🚀 Installation

```bash
# Cloner le dépôt
git clone https://github.com/TON-PSEUDO/DJASSA.git

# Accéder au projet
cd DJASSA

# Installer les dépendances
npm install

# Lancer le serveur de développement
npm run dev
```

L'application sera accessible à l'adresse indiquée dans le terminal.
